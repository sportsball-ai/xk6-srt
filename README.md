# xk6-srt

This is a K6 extension for testing SRT endpoints.

## Building

To build from a local clone:

```
XK6_EARLY_ACCESS=true xk6 build --cgo=1 --with github.com/sportsball-ai/xk6-srt=.
```

Or to build using the latest:

```
XK6_EARLY_ACCESS=true xk6 build --cgo=1 --with github.com/sportsball-ai/xk6-srt
```
